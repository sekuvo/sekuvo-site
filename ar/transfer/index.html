Transfer

From computer to phone,
with no network in between.

Sekuvo has no internet permission, so a secret reaches your phone only along a path you show it. This page walks through those paths: the easiest is aktar.html and QR, the most cautious is an envelope you build in your own terminal.

Download aktar.html

v1.0.0 · 53 KB · one file, runs from your own disk

SHA-256 · v1.0.085ee1729fda96072b36303074f21a170d5361c0577a920ef631bd6884d5b653d
How do I verify it?

Run the command for your system in a terminal; the output must match the value above exactly. The same value is published in the GitHub release notes. You can also keep it in Sekuvo as a Tool anchor (the fingerprint button on the home screen) and compare against your phone the next time you download.

# macOS / Linux shasum -a 256 aktar.html # Windows (PowerShell / cmd) certutil -hashfile aktar.html SHA256

A download, not a web page: the address bar shows file://. sekuvo.com never asks you for a secret. aktar.html currently speaks English and Turkish.

Why QR

Three doors stay shut.

Typing by hand breaks things

One wrong character in a 64-character API key and the key is dead. Typing a long private key into a phone is, in practice, impossible.

The clipboard leaks

Whatever you copy can be read by the app that is open at that moment, and cloud clipboards carry it to other devices. That is why Sekuvo never uses it as a path.

There is no network

The app has no INTERNET permission, so file sync, e-mail or a server are not options. Light travelling from a screen to a camera crosses no network at all.

Step by step

With aktar.html

  1. Download

    Get aktar.html with the button above or from the release page. It is one file; nothing to install.

  2. Verify

    Compute its SHA-256 and compare it with the published value. If they differ, do not open the file.

  3. Open

    Double-click it. The address bar shows file://, not a website, and the page never connects to the internet.

  4. Fill in and encrypt

    Write a title, pick a type (Account, Everyday, Card or Secure note), paste the secret or pick a .pem / .env file. Choose a backup password and press Encrypt and show the QR.

  5. Scan on the phone

    Sekuvo → ➕ → Import via QR. Large envelopes are split into several frames that cycle on screen; the phone collects them in any order. Enter the same password and the entry is added.

Don't even type the password

The transfer wizard

The ⇄ button on the home screen opens the transfer wizard. The phone generates a single-use password of letters and digits — immune to keyboard-layout differences — and, acting as a Bluetooth keyboard, types it into both password fields of aktar.html at once. Press Encrypt and show the QR on the computer and Scan QR in the wizard: the password is already on the phone, so you never type it.

What the QR carries

An envelope, never the secret.

Whoever photographs the QR gets only this. The transfer password becomes a key through 310,000 rounds of PBKDF2, which makes every guess slow; without the password the data field is noise.

{ "app": "vault", "version": 1, "kdf": { "algo": "PBKDF2WithHmacSHA256", "iterations": 310000, "salt": "…16 bytes, base64…" }, "cipher": "AES-256-GCM", "data": "…12-byte IV + ciphertext + 16-byte tag, base64…" }
Questions

Frequently asked

Does my secret go to the internet?

No. aktar.html encrypts with the browser's WebCrypto on your machine and draws the QR on your screen. Sekuvo has no internet permission; the camera image is decoded inside the app.

Why a downloaded file instead of a web page?

A web page that asks for secrets looks exactly like a phishing page. And a page on a server can change on every visit; the digest of a file you downloaded is fixed and checkable.

What about large files?

The entry limit is 256 KB. Large envelopes are split into several QR frames that cycle; the phone collects them in any order and shows which frames are still missing.

Which languages does aktar.html speak?

English and Turkish for now.

And from phone to computer?

The other direction is Bluetooth: your phone types into the computer like a keyboard, with nothing installed on the computer.
