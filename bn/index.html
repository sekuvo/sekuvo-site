নিরাপত্তা মডেল

বিশ্বাস নয়, যাচাই করা যায় এমন এনক্রিপশন।

প্রতিটি স্পর্শকাতর ফিল্ড AES-256-GCM দিয়ে সিল করা। কী কখনো কোনো সার্ভারে যায় না, কারণ কোনো সার্ভারই নেই; প্রতিবার আনলক করার সময় এটি আপনার ফোনে, আপনার মূল পাসওয়ার্ড থেকে তৈরি হয়।

AndroidManifest.xml — এর সব অনুমতি <uses-permission android:name="…USE_BIOMETRIC" /> <uses-permission android:name="…CAMERA" /> <uses-permission android:name="…VIBRATE" /> <uses-permission android:name="…BLUETOOTH_CONNECT" /> $ grep INTERNET AndroidManifest.xml (কোনো মিল নেই — এই অনুমতিটি আসলে নেই)

স্ক্রিন বন্ধ হলেই লক

স্ক্রিন অন্ধকার হওয়ার মুহূর্তেই কী মেমোরি থেকে মুছে যায় — ফোল্ডেবল ফোন ভাঁজ করাও এর মধ্যে পড়ে। একবার আনলক করলেই তা অ্যাপ, কীবোর্ড এবং অটোফিল একসাথে ব্যবহার করে।

ফোনের চেয়ে বেশিদিন টিকে থাকা ব্যাকআপ

একটি এনক্রিপ্টেড .vaultbak ফাইল, আপনার পছন্দের যেকোনো জায়গায় রাখা যায়। ফাইল এবং ব্যাকআপ পাসওয়ার্ড দিয়ে যেকোনো ডিভাইসে সবকিছু ফিরে আসে — পুনরুদ্ধারের পথটি সম্পূর্ণভাবে পরীক্ষিত।

পুনরুদ্ধারের কোনো ব্যাকডোর নেই

মূল পাসওয়ার্ড ভুলে গেলে তথ্য চিরতরে হারিয়ে যায়। এটাই নকশা: যে দরজা শুধু আপনিই খুলতে পারেন, তার নিচে কোনো বাড়তি চাবি লুকানো থাকে না।

From computer to phone

Long secrets aren't typed by hand.
Move them by QR.

SSH keys, .env files, recovery codes… aktar.html encrypts the secret on your computer and Sekuvo reads it with the camera. No server, no account, no clipboard in between — only light travelling from a screen to a lens.

  1. Download and verify

    aktar.html is a single HTML file. Download it, compare its SHA-256 with the value below, and open it from your own disk.

  2. Encrypt on the computer

    Paste the secret and choose a transfer password. Encryption runs inside the browser, on your machine; the envelope is drawn on screen as QR codes.

  3. Scan with the phone

    In Sekuvo: ➕ → Import via QR. Scan the frames, enter the same password, and the entry lands in your vault.

How do I verify it?

Run the command for your system in a terminal; the output must match the value above exactly. The same value is published in the GitHub release notes. You can also keep it in Sekuvo as a Tool anchor (the fingerprint button on the home screen) and compare against your phone the next time you download.

# macOS / Linux shasum -a 256 aktar.html # Windows (PowerShell / cmd) certutil -hashfile aktar.html SHA256

A download, not a web page: the address bar shows file://. sekuvo.com never asks you for a secret. aktar.html currently speaks English and Turkish.
