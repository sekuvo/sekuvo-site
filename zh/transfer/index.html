从电脑到手机，
中间没有网络。

Sekuvo 没有互联网权限，所以秘密只能沿着你指给它的路径到达手机。本页逐一说明这些路径：最简单的是 aktar.html 加二维码，最谨慎的是你在自己的终端里构建的信封。

在终端里运行适合你系统的命令，输出必须与上面的值完全一致。同一个值也发布在 GitHub 的发行说明里。你还可以把它存进 Sekuvo 的工具锚点（主屏幕上的指纹按钮），下次下载时与手机上的值比对。

为什么用二维码

三扇门始终关着。

手打会出错

64 个字符的 API 密钥里错一个字符，密钥就作废了。把一把长长的私钥手动输进手机，实际上做不到。

剪贴板会泄露

你复制的任何内容都可能被当时打开的应用读取，云剪贴板还会把它带到其他设备。所以 Sekuvo 从不把它当作路径。

没有网络

这个应用没有 INTERNET 权限，所以文件同步、电子邮件或服务器都不是选项。从屏幕到摄像头的光，不经过任何网络。

一步一步

使用 aktar.html

  1. 下载

    通过上面的按钮或发行页获取 aktar.html。它只是一个文件，无需安装。

  2. 校验

    计算它的 SHA-256，与公布的值比对。如果不一致，不要打开这个文件。

  3. 打开

    双击它。地址栏显示的是 file://，不是网站，页面永远不会连接互联网。

  4. 填写并加密

    写一个标题，选一种类型（账户、日常、卡片或安全笔记），粘贴秘密或选择一个 .pem / .env 文件。设定传输密码，然后按“加密并显示二维码”。

  5. 在手机上扫描

    Sekuvo → ➕ → 通过二维码导入。大信封会拆成多帧在屏幕上轮播；手机以任意顺序收集。输入同一个密码，条目就添加好了。

连密码都不用打

传输向导

主屏幕上的 ⇄ 按钮打开传输向导。手机生成一个由字母和数字组成的一次性密码——不受键盘布局差异影响——并作为蓝牙键盘，把它同时输入 aktar.html 的两个密码框。在电脑上按“加密并显示二维码”，在向导里按“扫描二维码”：密码已经在手机上，你永远不需要输入它。

问题

常见问题

我的秘密会上网吗？

不会。aktar.html 用浏览器的 WebCrypto 在你的机器上加密，并把二维码画在你的屏幕上。Sekuvo 没有互联网权限；摄像头画面在应用内部解码。

为什么是下载的文件而不是网页？

一个索要秘密的网页，看起来和钓鱼页面一模一样。而且服务器上的页面每次访问都可能变化；你下载的文件的摘要是固定且可校验的。

大文件怎么办？

单条目上限为 256 KB。大信封会拆成多帧二维码轮播；手机以任意顺序收集，并显示还缺哪些帧。

aktar.html 支持哪些语言？

目前是英语和土耳其语。

从手机到电脑呢？

反方向走蓝牙：你的手机像键盘一样往电脑里输入，电脑上什么都不用装。
