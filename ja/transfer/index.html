転送

パソコンからスマートフォンへ、
途中にネットワークなしで。

Sekuvo にはインターネット権限がないため、秘密はあなたが示した経路でしかスマートフォンに届きません。このページではその経路を順に説明します。いちばん簡単なのは aktar.html と QR、いちばん慎重なのは自分のターミナルで組み立てる封筒です。

aktar.html をダウンロード

v1.0.0 · 53 KB · ファイル 1 つ、自分のディスクから動く

SHA-256 · v1.0.085ee1729fda96072b36303074f21a170d5361c0577a920ef631bd6884d5b653d
どう検証する？

お使いのシステム向けのコマンドをターミナルで実行します。出力は上の値と完全に一致しなければなりません。同じ値は GitHub のリリースノートにも公開されています。Sekuvo に「ツールのアンカー」として保存しておき（ホーム画面の指紋ボタン）、次回ダウンロード時にスマートフォンの値と照合することもできます。

# macOS / Linux shasum -a 256 aktar.html # Windows (PowerShell / cmd) certutil -hashfile aktar.html SHA256

これは Web ページではなくダウンロードしたファイルです。アドレスバーには file:// と表示されます。sekuvo.com が秘密を求めることは決してありません。 aktar.html は今のところ英語とトルコ語のみです。

なぜ QR か

三つの扉は閉じたまま。

手入力は壊す

64 文字の API キーで 1 文字でも間違えれば、その鍵は使えません。長い秘密鍵をスマートフォンに手で打ち込むのは、実際には不可能です。

クリップボードは漏れる

コピーしたものは、そのとき開いているアプリに読まれる可能性があり、クラウドのクリップボードは他の端末にも運びます。だから Sekuvo はクリップボードを経路として使いません。

ネットワークがない

このアプリには INTERNET 権限がないため、ファイル同期、メール、サーバーは選択肢になりません。画面からカメラへ届く光は、どのネットワークも通りません。

手順

aktar.html で

  1. ダウンロード

    上のボタンかリリースページから aktar.html を入手します。ファイル 1 つだけで、インストールは不要です。

  2. 検証

    その SHA-256 を計算し、公開されている値と照合します。異なる場合はファイルを開かないでください。

  3. 開く

    ダブルクリックします。アドレスバーには Web サイトではなく file:// と表示され、ページがインターネットに接続することはありません。

  4. 入力して暗号化

    タイトルを書き、種類（アカウント、日常、カード、安全なメモ）を選び、秘密を貼り付けるか .pem / .env ファイルを選びます。転送パスワードを決めて「暗号化して QR を表示」を押します。

  5. スマートフォンで読み取る

    Sekuvo → ➕ → QR から取り込み。大きな封筒は画面上で切り替わる複数のフレームに分割され、スマートフォンは順不同で集めます。同じパスワードを入力すると項目が追加されます。

パスワードさえ打たない

転送ウィザード

ホーム画面の ⇄ ボタンで転送ウィザードが開きます。スマートフォンが英数字だけの使い捨てパスワードを生成し（キーボード配列の違いに影響されません）、Bluetooth キーボードとして aktar.html の 2 つのパスワード欄に同時に入力します。パソコンで「暗号化して QR を表示」、ウィザードで「QR を読み取る」を押すだけ。パスワードはすでにスマートフォンにあるので、あなたが打つことはありません。

ほかの経路

aktar.html を使いたくないとき

封筒 → QR ページ

ブラウザに何も暗号化させたくない？ 30 行のスクリプトで自分のターミナル上に封筒を組み立てます。このページは暗号文を QR フレームに変えるだけです。

「封筒 → QR」ページを開く →

テキストから取り込み

封筒をテキストとして運べる方法なら何でも使えます：➕ → テキストから取り込み、貼り付け、パスワードを入力。

コマンドライン：vault-clip.py

クリップボードやファイルから同じことを行い、QR をターミナルに直接描きます。

QR が運ぶもの

封筒であって、秘密そのものではない。

QR を撮影した人が得るのはこれだけです。転送パスワードは 310,000 回の PBKDF2 で鍵になり、推測の一回一回が遅くなります。パスワードがなければ、データ欄はただのノイズです。

{ "app": "vault", "version": 1, "kdf": { "algo": "PBKDF2WithHmacSHA256", "iterations": 310000, "salt": "…16 bytes, base64…" }, "cipher": "AES-256-GCM", "data": "…12-byte IV + ciphertext + 16-byte tag, base64…" }
質問

よくある質問

私の秘密はインターネットに出ますか？

いいえ。aktar.html はブラウザの WebCrypto であなたのマシン上で暗号化し、QR をあなたの画面に描きます。Sekuvo にはインターネット権限がなく、カメラの映像はアプリの中でデコードされます。

なぜ Web ページではなくダウンロードしたファイルなのですか？

秘密を求める Web ページは、フィッシングページとまったく同じに見えます。それにサーバー上のページは訪問のたびに変わりうるのに対し、ダウンロードしたファイルのダイジェストは固定で、検証できます。

大きなファイルは？

項目あたりの上限は 256 KB です。大きな封筒は切り替わる複数の QR フレームに分割され、スマートフォンは順不同で集めて、まだ足りないフレームを表示します。

aktar.html は何語に対応していますか？

今のところ英語とトルコ語です。

スマートフォンからパソコンへは？

逆方向は Bluetooth です。スマートフォンがキーボードのようにパソコンへ入力し、パソコン側には何もインストールしません。
