初回起動

初めて開くとき、マスターパスワードを設定します。保存するすべての秘密情報はこのパスワードから導出された鍵で暗号化されるため、唯一Sekuvoが復元を手伝えないものです — 続ける前に安全な場所に書き留めてください。

他の端末からの移行ですか？ ようこそ画面で「バックアップがあります — 復元する」をタップしてください。それでも先にこの端末のマスターパスワードを設定し、その後ファイル選択画面が自動的に開き、あなたのアイテムが戻ってきます。

あなたの端末に指紋または顔認証センサーがある場合、Sekuvoはセットアップ直後にその使用を提案します。これは利便性のための一層に過ぎません: マスターパスワードは常に機能し、工場出荷時リセットを乗り越えるのもこのパスワードです。

保存できるもの

4種類のアイテムが、人々が保管庫に保存するもののほとんどをカバーします:

  • アカウント / パスワード — ユーザー名、パスワード、サイトまたはアプリ。
  • 日常 — 氏名、電話番号、メール、住所。フォームが常に求めるもの。
  • カード — カード番号、有効期限、CVV、IBAN。
  • セキュアメモ — 自由なテキスト、スクリプト、鍵、復旧コード、設定ファイル用のサブタイプ付き。

アカウントと日常のアイテムはカスタムフィールドも受け付けます: 好きな「名前 + 値」のペアです。カスタムフィールドは組み込みのフィールドとまったく同様に暗号化され、他のフィールドが表示されるすべての場所に表示されます。

クリップボードを使わずに秘密情報を使う

クリップボードは他のアプリから読み取られる可能性があり、まさにそこで秘密情報が盗まれます。だからこそSekuvoは、値を目的地に直接届ける3つの方法を提供します。コピーすることも引き続き可能です — クリップボードは45秒後に自動的に消去されます — ですが、以下の3つのチャネルこそがこのアプリの存在理由です。

自動入力（端末内）

SekuvoはAndroidの自動入力サービスとして機能できるため、ログインフォームやカードフォームがあなたのアイテムを直接提示します。

有効にするには: Sekuvo → 設定 → 自動入力を有効にする → システムのリストからSekuvoを選択してください。このリストの名前は端末によって異なり、SamsungとAndroid 14以降ではパスワード、パスキー、自動入力 → 優先サービス、素のAndroidでは自動入力サービスとなります。

その後、どのアプリでもユーザー名、パスワード、カードのフィールドに触れると、対応するアイテムがキーボードの上に表示されます。保管庫がロックされている場合、先にロック解除の手順が表示されます — ロックされている間、システムには一切何も渡されません。

Sekuvoキーボード（端末内）

キーボード拡張機能は、どのアプリのどのフィールドにも、コピーの手順なしで保存された値を入力します。

有効にするには: Sekuvo → 設定 → キーボードを有効にする → システムのリストで有効化し、必要なときにキーボード切り替えから「Sekuvoキーボード」を選択してください。

最近使用したアイテムが上部に表示され、🔍はタイトル、ユーザー名、住所を検索します。保管庫がロックされている間、キーボードにはクイックアクセスに設定されたアイテムのみ表示されます — 下記を参照してください。

Bluetoothでコンピューターに入力

あなたの端末はBluetoothキーボードとして機能し、コンピューターのカーソル位置に秘密情報を入力できます。コンピューターには何もインストールされず、Windows、macOS、Linuxで動作し、値がクリップボードやネットワークに触れることは決してありません。Android 9以降が必要です。

手順

  1. Sekuvoでアイテムを開き、入力したいフィールドの横にある💻アイコンをタップします。この画面を開いたままにしてください — 端末はこの画面が開いている間だけキーボードとして認識されます。
  2. コンピューターで端末を新しいBluetooth機器として追加します: Windowsでは設定 → Bluetoothとデバイス → デバイスを追加 → Bluetooth、macOSではシステム設定 → Bluetooth。
  3. 両側でペアリングコードを確認します。
  4. 端末に戻り、リストからコンピューターを選択し、「接続済み」と表示されるのを待ちます。
  5. コンピューター側のキーボードレイアウトを選択してください — 端末側ではありません。キーコードを解釈するのはコンピューターなので、レイアウトを間違えると@ " ? のような文字が気づかないうちに別の文字に変わってしまいます。
  6. 値を入力したいコンピューター側のフィールドをクリックします。
  7. 端末で入力をタップします。3秒のカウントダウンの後 — これはあなたがそのフィールドをクリックする時間を確保するためのものです — 値が1キーずつ入力されます。

接続されているのに何も入力されない

ほとんどの場合、原因は同じです: コンピューターが以前にあなたの端末を普通の電話としてペアリングしていたため、キーボードサービス（HID）を有効にしたことがない、というものです。接続自体は成功しますが、キー入力がどこにも届きません。

  1. コンピューター側でペアリングを解除します（デバイスを削除）。
  2. 端末側でも解除します（Bluetooth設定でペア解除）。両側とも重要です。
  3. Sekuvoで💻画面を開き、開いたままにします。
  4. コンピューター側から始めて再度ペアリングします。
  5. Windowsで確認するには: デバイスマネージャー → ヒューマンインターフェースデバイスに、今度はBluetooth HID機器が表示されるはずです。

macOSでは、最初の接続時にキーボード設定アシスタントが開くことがあり、shiftキーの隣のキーを押すよう求められます。そのウィンドウが閉じられるまで、macOSは何も処理しません — これがMacで「接続済みだが無反応」になる一般的な原因です。

速度と、その確認方法

キー入力は1つずつ送信されるため、長い秘密情報には実際に時間がかかります — ダイアログには見積もりが表示されます。3段階の速度が用意されており、「安全」がデフォルトになっているのは意図的です。速度を上げる前に⏱ 速度テストを使ってください: 10個の同一のブロックをスペースで区切って入力し、測定された1秒あたりの文字数を報告します。1つでもブロックが異なる場合、その速度はこのコンピューターでは安全ではありません — 1段階下げてください。

速度テストは診断としても使えます: 何も入力されない場合はペアリングの問題、文字が乱れる場合はレイアウトの問題、入力が途中で止まる場合は速度の問題です。

入力中は進行状況バーと停止ボタンが表示されます。送信キューが詰まった場合、Sekuvoは待機時間を増やしながら再試行し、それでも失敗する場合は停止して、どの文字で止まったかを知らせます — 秘密情報が黙って途中まで入力されたままになることはありません。

ロックの仕組み

保管庫が開かれている画面が消えた瞬間にロックされます — 折りたたみ式端末を閉じることも含まれます。その瞬間に鍵はメモリから消去されます。アイテムのタイトルはリストに表示され続けることがありますが、何も復号できません。

画面が点いたままアプリを終了してもロックされません。これは意図的です: アプリ、キーボード、自動入力は1つのセッションを共有しており、そうでなければパスワードを貼り付けるためにブラウザに切り替えるだけで、作業の途中で締め出されてしまいます。

クイックアクセス — 意図的なトレードオフ

明示的に「パスワードなしでキーボードから使う」と設定したアイテムは、別のデバイス鍵で暗号化されて2回目の保存が行われ、キーボードが保管庫のロック中でもそれらを読み取れるようにします。

このトレードオフは明確に示されています: そのようなアイテムは、マスターパスワードではなく、あなたの端末の画面ロックによって保護されます。パスワードはそこに置かないでください。この設定はデフォルトで無効です。唯一の例外は新規の日常アイテムで、氏名や電話番号はまさに手元にすぐ用意しておきたいものであるため、最初から有効になっています — どちらも個別に無効化できます。

バックアップと復元

システムバックアップ（Googleバックアップ、端末移行）は意図的に無効化されているため、保管庫が端末から出る方法は、あなたが選ぶ1つだけです: 設定 → 暗号化されたバックアップを作成。

バックアップパスワードを選択します — マスターパスワードとは異なるものにしてください。バックアップパスワードは最終的にコンピューターに入力されるものだからです。結果として1つの.vaultbakファイルが生成され、Drive、SDカード、USBメモリなど好きな場所に保存できます。

このファイルは端末に依存しません: 独自のソルトと鍵導出パラメータがヘッダーに含まれています。ファイルとバックアップパスワードがあれば、工場出荷時リセット後でも、どの端末でもすべて復元できます。設定 → バックアップから復元、または新規インストール時のようこそ画面から復元してください。

復元では既存のものに追加またはすべて置き換えを選べます。どちらも何かが書き込まれる前に検証されます — 間違ったパスワードは認証の段階で失敗し、新しいデータが確認されるまで何も削除されません。

コンピューターから秘密情報を持ち込む

長い鍵を端末に手で入力するのは、ミスが起きやすい場面です。Sekuvoはそれらを暗号化された封筒として、2つの方法で転送します: あなたが貼り付けるテキスト、またはあなたがスキャンするQRコードです。

端末上で: ➕ボタンはQRでインポートとテキストからインポートを提供します。QRインポートはカメラを開きます。画像は端末上でデコードされ、複数画像にわたる転送は収集中の進行状況を表示します。

コンピューター側のツール

これらの封筒を作成するツールは1つのHTMLファイルであり、意図的にウェブサイトではなくダウンロードファイルです。sekuvo.comがあなたに秘密情報を尋ねることは決してありません。もしそうするページがあれば、それはフィッシングサイトとまったく同じに見えるはずです。

  1. GitHubでプロジェクトを開き、Releasesに移動します。
  2. 最新リリースからaktar.htmlをダウンロードします。
  3. 横に公開されている値でSHA-256を確認します: macOSまたはLinuxではshasum -a 256 aktar.html、Windowsではcertutil -hashfile aktar.html SHA256。
  4. ファイルをダブルクリックして開きます。ディスクから実行されます — アドレスバーにはウェブサイトではなくfile://が表示されます。
  5. テキストを貼り付け、転送パスワードを設定すると、テキストまたはQRコードとして封筒が生成されます。
  6. 端末でスキャンまたは貼り付けを行い、同じパスワードを入力して、追加または置き換えを選択します。

すべての暗号化はあなたのブラウザ内、あなたのマシン上で行われます。コマンドライン用のvault-clip.pyもあり、クリップボードまたはファイルから同じことを行い、ターミナルにQRコードを描画することもできます。

ツールを使いたくない場合

この封筒はオープンなフォーマットであり、Sekuvoでしか作れないものではありません: PBKDF2-HMAC-SHA256（310,000回）、AES-256-GCM、それらが小さなJSONオブジェクトにラップされています。すでに読んだ約30行のコードで自分で作成し、結果をテキストからインポートに貼り付けることができます — アプリはどのツールがそれを作成したか知る術がなく、気にもしません。

作り方はリポジトリにあります: docs/kendi-zarfini-uret.md（トルコ語で書かれています）。

使用履歴

Sekuvoは、どのアイテムのどのフィールドが、いつ、どこへ送られたかを記録します: クリップボードへ、Bluetooth経由でコンピューターへ（送信先の端末名付き）、またはキーボードからアプリに入力された場合。コンピューターが侵害されたとき、これは「何がそこに渡ったか、何を変更する必要があるか」に答えます。

この履歴はあなたのアイテムと同じ鍵で暗号化されており、値そのものが記録されることは決してありません — イベントの種類、フィールド名、送信先のみです。アイテムを削除すると、その履歴も削除され、設定からすべてを消去できます。

パスワード生成ツール

ホーム画面の🎲アイコン、またはアイテム編集中のパスワードフィールドの横からアクセスできます。暗号学的な乱数源を使用し、8～64文字を生成し、文字クラスの選択が可能で、互いに紛らわしい文字を除外でき、結果のエントロピーをビット単位で表示します。
